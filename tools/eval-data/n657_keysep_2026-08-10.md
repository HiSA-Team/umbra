# N657 separated-key hardware campaign — 2026-08-10

Board: NUCLEO-N657X0-Q. Firmware built from the working tree based on `cdc0ac9`,
package tag v2, distinct `K_update` and `K_attest`, one attestation slot, enclave
version 2 at flash.
The image was built and programmed through `cargo xtask flash n657` with
`HOST_APP=bare_metal`, `UMBRA_VERSION_BIND=1`, `UMBRA_KEEP_MASTER_KEY=1`,
`UMBRA_ATTEST_SLOTS=1`, `UMBRA_CREATE_BEST_SLOT=1`, and
`UMBRA_ENCLAVE_VERSION=2`. The board was then moved to Flash-Boot and reset.

## Boot and valid-path smoke test

The first fresh quote verified (`tag OK`, `nonce fresh`, version/floor 2,
`VERDICT TRUSTED`). A signed 5,808-byte `ndes` update to v3 returned `OK`; the
subsequent fresh quote confirmed version/floor 3. Device timings for that smoke
update were 1,047,307 copy cycles, 18,250 authentication cycles, 549,484 probe
cycles, 55,415,433 flash cycles, and 3,840,925 verification cycles.

evidence and does not extend the mechanized theorem boundary.
